## 🔬 라이브러리 없이, 직접 구현하기

- **[rag](https://github.com/wjdjdakf17/rag)** — RAG 검색 파이프라인을 전부 손으로 구현
  청킹 → TF-IDF / BM25 → RRF 하이브리드 검색 → recall@k·MRR 평가까지, 의존성 없이
- **[harness](https://github.com/wjdjdakf17/harness)** — Claude Code·Codex 같은 에이전트 런타임이 내부에서 어떻게 도는지 이해하려고 만든 에이전트 하네스. TypeScript, 의존성 0
- **[websocket](https://github.com/wjdjdakf17/websocket)** — RFC 6455를 읽고 WebSocket 직접 구현
  핸드셰이크, 프레임 파싱, 종료 시퀀스를 직접 짜고 브라우저 네이티브 WebSocket과 상호동작 테스트
